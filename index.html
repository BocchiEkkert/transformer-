真实模型会把“注意力→加&归一化→前馈→加&归一化”这一块堆叠很多层（原论文是 6 层），这里只演示一层。
把整个 Transformer 想象成一间会议室：每个词是一个与会者，手里拿着一个小本子（向量）。
注意力 = 开会交流：每个人问一圈“谁跟我有关”，把相关的人说的话摘抄到自己的本子上。
前馈网络 = 散会后各自消化：每个人独立地把本子上的内容整理、推理。
开会 + 消化反复很多轮，每个人对整句话的理解就一层比一层深。

1词是怎么变成数字的？（Embedding）

计算机不认识 “cat”，只认识数字。所以第一步是查表：

① 分词：I like cat → 三个 token。词表里约定 I=0、like=1、cat=2，所以得到 ID 序列 [0, 1, 2]。
② 查表：有一张训练好的大表 E，每一行是一个词的 10 维向量。用 ID 当行号取出三行，按原顺序叠起来，就得到一个 3×10 的矩阵。

这张表就像一本“词的身份证册”：每个词有一串 10 个数字的特征。训练的时候，意思相近的词会慢慢得到相近的数字。推理时表是固定的，cat 的向量只由它的 ID 决定——同一个词不管在什么句子里，这一步查到的都一样。

形状变化（带 batch 维）：[1,3] → [1,3,10]，即 1 句话、3 个词、每词 10 个特征。图中颜色深浅只是随手画的示意，不是真实数值。

2位置编码：告诉模型“谁在第几个”

注意力是同时看所有词的，它天生不知道顺序。“猫喜欢我”和“我喜欢猫”如果只看词袋，是一模一样的。所以要给每个词再加上一个位置向量：

Xp = √10 · E[IDp] + PE(p)

原论文用的是固定公式（不用训练）生成位置向量：把 10 维拆成 5 对 (sin, cos)，每一对用一个不同的“频率”。

把每一对 (sin, cos) 想成一个时钟的指针：位置越靠后，指针转得越多。
有的钟转得飞快（秒针），有的钟转得极慢（时针）。一个词在第 p 个位置，就是读一下所有钟现在的指针方向。快慢钟合起来，就能唯一确定“你在第几位”，就像秒针 + 分针 + 时针能读出具体时刻。

拖动位置，看三个“时钟”怎么转

位置 p2
cat 在位置 2，最快的那对时钟读数是 (sin 2, cos 2) ≈ (0.9093, −0.4161)。这两个数会加到缩放后 cat 向量的前两维上，其余维度同理逐个相加。

加完之后形状没变，仍是 3×10，只是每一行里多了“我排第几”的信息。上图的位置编码数值是用公式真实算出来的；词向量部分是示意。

为什么正余弦能表达“相对位置”？（选读）

三角函数的加法公式保证：位置 p 向后挪 Δ 步，等价于把 (sin, cos) 这个小向量旋转一个只与 Δ 有关的角度。所以“I→like”和“like→cat”都隔一个位置，对应的是同一个旋转。再加上两个位置的编码做点积只和距离 p−q 有关，模型就更容易学到“相邻”“隔两个”这类关系。

需要说明：这些结构是编码提供的条件，模型具体怎么利用，由后面学出来的权重决定。

3自注意力：Q、K、V 到底是什么？

现在每个词都带着“词义 + 位置”。接下来让它们互相交流——这是整个 Transformer 的核心。

想象你在图书馆查资料，一个词要做的事和你一样：
Q 查询：你心里的问题——“我（cat）想找：谁在表达‘喜欢’这个动作？”
K 键：每本书书脊上的标签——“我（like）是个动词，表示喜好”。
V 值：书的正文——找到之后你真正抄走的内容。
先拿“问题”去和每个“标签”比对，算出相关度；再按相关度从每本书的“正文”里抄一点回来。

三个词、三张独立的“变身矩阵”

同一份输入 X（3×10），分别乘三张各自训练出来的矩阵，得到三种身份：

Q = X·WQ　　K = X·WK　　V = X·WV　　（W 都是 10×5，所以 Q、K、V 各是 3×5）

为什么要三张而不是直接用 X？因为“用来被找到的特征（K）”和“被找到后要交出去的内容（V）”并不需要相同。比如 like 用“我是动词”来被匹配，却可以交出“喜好的程度、情感倾向”等另一组信息。分开之后，模型才有这个自由。

Q 和 K 相乘：算“有多相关”

cat 的 Q 和 like 的 K 做点积（对应位置相乘再求和），得到一个数字：

scat,like = qcat · klike = Σℓ=1..5 qcat,ℓ·klike,ℓ = |q|·|k|·cosθ
点积就是在量“两个箭头方向有多一致”：方向一致 → 数很大（很相关）；互相垂直 → 0（无关）；方向相反 → 负数（排斥）。
这里“相关”不是字面相似，而是训练学出来的相关——比如让“动词”去找“和它搭配的名词”。

把所有词一起算，Q(3×5) × Kᵀ(5×3) = S(3×3)：第 i 行第 j 列就是“第 i 个词对第 j 个词的原始打分”。

本页后面只盯着 cat 这一行，原始分数假设为 [0, 2, 4]。意思是：cat 觉得自己跟自己最相关（4），其次是 like（2），I 最不相关（0）。其他行用“·”省略。

4为什么要先除以 √5？

每个分数是 5 项乘积相加。如果每一项大致是均值 0、方差 1 的随机数，那么加起来的方差是 5，标准差是 √5 ≈ 2.236。维度越大，分数越容易“飘得很大”。

分数很大会怎样？Softmax 会变得极端：一个位置接近 100%，其他接近 0。这时候梯度几乎为零，模型学不动。所以除以 √dk 把分数拉回合理范围：

S̃ = S / √dk，dk = 5　→　cat 这行 [0, 2, 4] 变成 [0, 0.894, 1.789]

排序没变（cat > like > I），变的是“有多偏心”。下一节的实验里可以直接对比。

5Softmax 与乘 V：把“分数”变成“抄多少”

Softmax：分数 → 分配比例

对 cat 的三个缩放分数，先各取指数 ex，再除以指数之和：

Pij = exp(S̃ij) / Σk exp(S̃ik)

结果是三个非负数、总和为 1，可以理解为：cat 手上有 100% 的注意力，怎么分给 I、like、cat。cat 这行变成 [0.106, 0.259, 0.635]。每个词（每一行）各自单独分配，所以 P 仍是 3×3，每行和为 1。

用指数有个好处：分数差一点，权重就拉开一截（like 比 I 高 0.894，权重就是 I 的 e0.894 ≈ 2.45 倍）；而且它处处光滑可导，训练时能用梯度“微调该多看谁”。

乘 V：按比例把内容抄回来

知道要从 like 抄 26% 还不够，还得看 like 的正文（V）写了什么。cat 的新向量就是三个 V 的加权和：

hcat ≈ 0.106·vI + 0.259·vlike + 0.635·vcat

矩阵写法是 P(3×3) × V(3×5) = H(3×5)，三个词同时算完。这样 cat 的新向量里已经混进了 I 和 like 的信息。

注意力计算器：拖动分数，看权重和输出怎么变

选一个发起查询的词：
① Softmax 之后的注意力权重
② 乘 V：假设三个词的值向量第一维分别是 2、4、6（原文的设定）

cat 默认就是原文的 [0, 2, 4]，I 和 like 两行是我为演示随便设的示意分数。试试：把 √5 缩放关掉，再把 cat 的分数拉到 8，看权重怎么“塌”成一个词。

换句话说：Q·K 决定“看谁、看多重”，Softmax 把它规整成分配方案，乘 V 才真正把内容取回并混合。
这就是一个可以求导的“软字典查询”——普通字典是精确匹配只返回一条，注意力是模糊匹配、返回所有条目的加权混合。

训练时，翻译的误差会沿着 H=PV 同时传回 V 的投影，也沿着 P 传回 Q、K 的投影，三张矩阵就这样一起学出来。推理时它们都固定，但每句话算出来的分数和权重仍然不同。

7残差连接 + 层归一化（Add & Norm）

注意力的输出 A 出来了，但不能直接用。原论文做两件事（Post-LN 顺序）：

R = X + A　　　H = LayerNorm(R)

① 残差连接：在原稿上“批注”，而不是重写

X 是 cat 进入注意力前的向量，已经有词义和位置。A 是注意力从上下文里收集来的补充信息。把它们逐元素相加，意思是：保留原来的，再叠加新学到的。比如 cat 第一维原值 0.8，注意力给的更新量是 −0.1，相加得 0.7。
更重要的是训练：反向传播时梯度可以顺着“+”这条直路一路传回去，不用每次都穿过注意力，这是深层网络能训练起来的关键之一。

② 层归一化：把每个词的数值拉回统一尺度

对每个词自己那一行的 10 个数，算均值 μ 和标准差 σ，减均值、除以标准差，再用学出来的 γ、β 缩放平移：

Hpj = γj · (Rpj − μp) / √(σp² + ε) + βj
层层相加、相乘之后，数字可能越来越大或越来越小，后面的层就“吃不消”。层归一化像是每层之后给每个词的数值统一调一下音量，让下一层总是在差不多的范围里工作。每个词只看自己那一行，互不影响；γ、β 有 10 个数，三个词共享。

8前馈网络 FFN：为什么注意力之后还要“再加工”？

先看注意力给了我们什么：

矩阵形状cat 那一行是什么
P（每头）3×3给 I、like、cat 各分多少权重
H = P·V（每头）3×5三个位置的 V 按比例加权平均出的 5 个特征
A3×10两个头拼接并混合后的 10 个特征
LayerNorm(X + A)3×10真正送进 FFN 的 10 个特征

关键在这里：每个头输出的 H 本质上是 V 的加权平均——只是“混合”，没有做出新的特征组合。

注意力和 FFN 的分工：
注意力 = 词和词之间“传话”（跨位置交换信息）；
FFN = 每个词自己“动脑子”（在位置内部做非线性加工）。
没有 FFN，堆再多层也只是反复“取平均”；有了 FFN，模型才能算出“a 和 b 的差”“这个模式是否出现”之类的新特征。

FFN 做三步：升维 → 激活 → 降维

Z = H·W₁ + b₁　　G = ReLU(Z) = max(0, Z)　　F = G·W₂ + b₂

I、like、cat 共用同一套权重，每行只用自己的数据，互不交流，所以可以并行算。

为什么要升维？为什么要 ReLU？

升维：W₁ 的 20 列相当于 20 个“探测器”，每个探测器用不同的加权组合来检查这个词的特征，还有自己的偏置当作“门槛”。探测器越多，能组合出的新特征越多。
ReLU：负的变 0、正的保留，相当于“这个探测器有没有被触发”。没有它，两次矩阵乘法会合并成一次，等于白做（升不升维都一样）。

用一个迷你 FFN 算“两个特征的差距”

设 cat 向量里有两个特征 a、b。让三个隐藏单元分别计算 a+b、a−b、b−a，再过 ReLU。拖动 a、b 看哪些单元被触发。

a2.0
b1.0
原文的例子：输入 [2,1] 得 [3,1,0]，输入 [1,2] 得 [3,0,1]——两个输入的“和”相同，但触发了不同的单元，降维时被读成不同的结果。把 ReLU(a−b)+ReLU(b−a) 相加，就得到了绝对差 |a−b|，这是线性层单独做不到的。
FFN 还有一层“知识库”的解释（研究观点，选读）

有研究（Geva 等，2021）把 FFN 看作键值记忆：第一层的每个神经元像一个“模式检测器”，第二层决定模式出现后“往向量里写什么”。另一项研究（Dong 等，2021）发现：只有注意力、没有残差和 FFN 的网络，层数一多各位置的表示会越来越相似。这些结论各自有前提条件，不等于已经把 Transformer 完全弄清楚，但解释了 FFN 为什么不可或缺。

FFN 之后，会再做一次 LayerNorm(H + F)（把 FFN 的输入 H 加回来，同样是残差 + 归一化），形状仍是 3×10。

10解码器入口：目标词嵌入、位置、因果掩码

输入是什么？

解码器的输入是目前已经生成的译文。第一轮只有开始符 SOS（假设 ID=0）；如果模型生成了“我”（假设 ID=1），第二轮前缀就是 [SOS, 我]，以后每生成一个词就追加一个。处理方式和 §1、§2 完全一样：查目标语言的嵌入表 → 乘 √10 → 加位置编码（SOS 在位置 0，位置向量前两维是 [0, 1]；“我”在位置 1，是 [0.8415, 0.5403]）。

逐词生成：点一下，前缀长一个

因果掩码：不许偷看答案

解码器自己的“自注意力”有个规则：第 p 个词只能看第 p 个及之前的词，不能看后面的。因为真正推理时，后面的词根本还没生成；训练时如果允许偷看，模型就会靠抄答案作弊，没法学会预测。

做法是在 Softmax 之前，给不允许看的位置加上 −∞，变成指数后就是 0 权重：

P = softmax( Q·Kᵀ / √5 + Mask )，Mask = [[0, −∞],[0, 0]]（两个词的前缀）

点击一行，看这个词“能看到谁”

位置编码告诉模型“每个词坐在第几格”，掩码规定“每个词能看哪几格”。一个管标号，一个管视野。

11交叉注意力：译文去“翻”原文

解码器先做完带掩码的自注意力 + Add&Norm，得到状态 R。然后进入最关键的一步：用目前的中文状态，去英文的理解笔记 M 里找信息。

Q = R·WQ（来自解码器）　　K = M·WK，V = M·WV（来自编码器）
这像一位译者：Q 是“我刚写完‘我’，下一个词该翻哪？”（来自译文）；K 是英文每个词的“索引标签”；V 是英文每个词的“实际内容”。
所以 Q 必须来自提问的一方（解码器），K、V 必须来自被查阅的一方（编码器的 M）。如果改用译文自己的 V，它只有 SOS、我 两个位置，根本没有英文的信息可取。
“我” 发起的查询（示意权重）
假设某个头里权重是 [0.1, 0.7, 0.2]：它取 0.1·v(I) + 0.7·v(like) + 0.2·v(cat)，主要从 like 取料，这正好能帮助预测中文的“喜欢”。

R（译文状态）2×10
M（英文理解）3×10
Q=R·WQ2×5
K, V = M·W各 3×5
P = softmax(QKᵀ/√5)2×3（行=目标位，列=源位）
H = P·V2×5 → 两头拼接 2×10

这里没有掩码：源句三个词是已经给定的，全部可以看。之后 C 加回 R、层归一化，再过一次 FFN（同 §8）。

12输出：Linear + Softmax → 下一个词

取最后一层解码器在“我”那个位置的 10 维向量 h。Linear 用一个 10×5 的矩阵 Wout，给词表里每个候选词打一个分（叫 logit，可以是负数）：

z = h·Wout　　1×10 × 10×5 = 1×5

然后 Softmax 把这 5 个分数变成概率，沿词表方向归一化（注意：注意力里的 Softmax 是沿“被查阅的位置”归一化，两者方向不同）：

pj = exp(zj − m) / Σk exp(zk − m)，m = max z　（减最大值只是防止数值溢出，结果不变）

词表概率 + 一个“温度”旋钮

温度 T1.0
T=1 时就是原文的表格：喜欢 70.76%、猫 14.29%、我 7.84%……（logits 为示意）。“温度”是常见的解码技巧，原教程没有，这里顺手放进来帮助理解：T 越小越“自信”、越接近贪心；T 越大越“发散”。

贪心解码就是每一步选概率最大的词。因为 Softmax 不改变大小顺序，直接取 logits 最大值效果一样。选出“喜欢”后，把它接到前缀，变成 [SOS, 我, 喜欢]，下一轮继续；等选出“猫”再选出 EOS 就停止。去掉结束符，最终译文就是 “我喜欢猫”。

注意区分三层输出：① 概率分布（一行 5 个概率）→ ② 单轮选出的一个词 → ③ 反复多轮拼成的整句译文。

一句话回到最初的问题：为什么注意力有效？

因为它让每个词都能根据内容、一步直达地从整句话里挑选相关信息（Q·K → Softmax → ×V），而且所有位置可以并行计算，适合大规模训练；再配上 FFN 做加工、残差与归一化保证深层可训练，就构成了今天的大模型基石。

14常见疑问

Q、K、V 是不是随便取的名字？为什么叫“查询、键、值”？

名字来自“字典/数据库查询”的比喻：用查询（Query）去匹配键（Key），取回对应的值（Value）。区别在于普通字典是精确匹配只返回一条，注意力是可微的模糊匹配，返回所有值的加权混合。这个思路和更早的“记忆网络”“软寻址”一脉相承。

注意力的 n×n 权重矩阵本身有语义吗？

它只是“路由方案”：谁给谁分了多少，不含内容。真正带内容的是乘 V 之后的输出。需要小心的是，“权重高 = 这个词对结果更重要”并不总是成立，学界对“注意力能不能当解释”一直有争论。

Transformer 现在被研究透彻了吗？

没有，工程跑在理论前面。比较清楚的是它的表达能力，以及一些具体电路（例如 induction heads：看到 “A B … A” 就倾向预测 B，和上下文学习密切相关）。有证据但没定论的包括 FFN 是不是知识库、深层表示趋同、上下文学习像不像在前向传播里做梯度下降。基本没搞懂的是规模变大后为什么会突然出现新能力、知识具体怎样分布在参数里。

原作者是怎么想到的？

不是一步灵感，而是一条演化路线（以下为公开历史的概括，细节可能有出入）：2014 年 Bahdanau 在机器翻译里给 RNN 加了“回头看”的注意力，解决“整句压成一个向量”的瓶颈；之后有简化打分、有不依赖 RNN 的纯注意力尝试，以及记忆网络、神经图灵机的“软寻址”思想；而 RNN 必须逐词顺序计算、训练太慢，于是 2017 年论文《Attention Is All You Need》干脆把循环整个去掉，只留注意力，再补上位置编码、残差、层归一化、FFN 等部件让它稳定可训练。
